## 环境与依赖

Python 3.11，依赖见 `requirements.txt`：

```
numpy==2.4.6
scipy==1.17.1
openpyxl==3.1.5
pandas
matplotlib
lxml
```

```bash
python -m pip install -r requirements.txt
```

### 官方输入

官方原题与附件不随仓库分发。程序运行时需要：

```
C题/C题.pdf
C题/附件/附件1.xlsx ~ 附件4.xlsx
C题/附件/附件5/result1.xlsx、result2.xlsx、result3.xlsx、result4-2.xlsx、result4-3.xlsx
```

各分支模块通过参数或环境变量接收这些路径，详见对应源码。

## 结果说明

- `结果/Q1/` 含完整轨迹、对偶值、灵敏度分析与输出校验记录。
- `结果/Q2/R2/forecasts` 是完整的 334 天派生预测缓存，`Q42` 的运行依赖它。
- `结果/Q2/M0/trajectory.csv` 与 `结果/Q43/ledger.csv` 仅包含 3 月 20 日、6 月 21 日、
  9 月 23 日、12 月 21 日及各自次日，**不是全年账本**；年度统计见相应汇总表。
- `图表数据/Q1/图片` 与 `图表数据/Q4/图片` 为已生成的论文用图。
