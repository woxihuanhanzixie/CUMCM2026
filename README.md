# CUMCM 2026 C题 —— 微网与外部电网电力调控策略

2026 年全国大学生数学建模竞赛 C 题参赛作品。

本仓库收录最终成果：五份结果表、论文、图表、计算结果与程序源码。
官方原题与附件未收录，运行需自行准备。

### 未收录内容

本仓库是参赛支撑材料的**展示子集**。以下材料保留在完整的本地支撑材料目录中，未纳入本仓库：

- 限定实验源码与已测数值汇总、独立证书、Q3 误差联接（`实验/`）
- Q3 原输入哈希及三分支前两日对照账本（`核验依据/`）
- 统一执行入口 `操作.py`、`工具/执行入口.py`、`工具/实验入口.py`
- 逐文件校验清单（`文件校验.json`、`支撑材料文件列表.csv`、`整理来源.json`）
- 验收与核验记录（`验收结果.json`、`答案核验.json`）、`使用说明.txt`

因此本仓库**不含**统一运行入口，`程序/` 下是可直接导入的源码模块，
需按各分支的模块接口自行调用。

## 环境与依赖

Python 3.11，依赖见 `requirements.txt`：

```
numpy==2.4.6
scipy==1.17.1
openpyxl==3.1.5
pandas
matplotlib
lxml
```

```bash
python -m pip install -r requirements.txt
```

### 官方输入

官方原题与附件不随仓库分发。程序运行时需要：

```
C题/C题.pdf
C题/附件/附件1.xlsx ~ 附件4.xlsx
C题/附件/附件5/result1.xlsx、result2.xlsx、result3.xlsx、result4-2.xlsx、result4-3.xlsx
```

各分支模块通过参数或环境变量接收这些路径，详见对应源码。

## 结果说明

- `结果/Q1/` 含完整轨迹、对偶值、灵敏度分析与输出校验记录。
- `结果/Q2/R2/forecasts` 是完整的 334 天派生预测缓存，`Q42` 的运行依赖它。
- `结果/Q2/M0/trajectory.csv` 与 `结果/Q43/ledger.csv` 仅包含 3 月 20 日、6 月 21 日、

## 已知限制

1. **论文终稿未收录**。`微网与外部电网电力调控策略_核心修订版.docx` 为随附稿，
   论文与图表数据的逐项对应关系以最后采用的正文为准。
2. **18 个年末边界空格缺少来源**：`result2`/`result4-2` 的 `计划购电量!EO335、EP335、EQ335`，
   `result3`/`result4-3` 的计划购电量与调整购电量各自的 `EO335、EP335、EQ335`。
   这 18 格缺少跨年订单及相应汇总来源，**不代表 0**，保持空白未补零。
   明细见 `答案/缺少来源说明.txt`。
3. **模板无时刻标签的储电量空白与日期承接空白不代表 0**，保持原样；Q3 三行"无/0"说明保持。
4. **Q43 历史证据不完整**：原年度逐次预测 / 合同 / LP 历史过程证据不完整。
5. `程序/` 中的 `run_small`、`regression`、`run_tests` 等文件为源码模块保留，
   不是可直接执行的独立入口。
